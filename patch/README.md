# Patch

`DBZ-english-v0.4.ips` is the current English patch (experimental; may still have bugs).

Apply it to your own copy of the original Japanese game with Lunar IPS, Floating IPS or
`perl tools/applyips.pl <original game file> patch/DBZ-english-v0.4.ips out.gb`.
The patched game is expanded to 1 MB (MBC5): each story scene lives in its own bank. Existing saves keep working.
